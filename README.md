### 運用メモ
- **登録に承認は無い**（2026-09-19〜）。登録した瞬間から出席できる
- **既存会員**は旧シートから取り込み済み（2026-09-19、109名・出席507件・開催93回）。初期暗証番号は共通の4桁（耕平さんが会員に伝える）。名前は旧参加表の表記そのまま → 当日は「登録」ではなく「ログイン」
- **共通の暗証番号のままの人**（2026-11-17〜）: 同じ番号を3人以上が使っていたら「共通の番号」とみなす（`gas/logic_auth.js` の `isCommonPin`）。一般の会員はログインすると「暗証番号を変えてください」の画面になり、変えるまで出席できない。**管理画面に入れる人（管理者の印・部長・副部長・事務長・副事務長）は共通の番号ではログインできない** → ミヤが管理画面の［暗証番号リセット］で個別の番号にする。新しい番号がほかの人と重なって共通になる場合は断る。番号を変えると合鍵（トークン）を作り直し、ほかの端末はログアウトになる
- **管理画面に入れる人**: 会員タブの `管理者` にチェックがある人と、区分が 部長・副部長・事務長・副事務長 の人（2026-11-17〜 区分だけで入れる。`gas/logic_auth.js` の `KUBUN_ADMIN`）
- **参加者・開催の一覧**（2026-10-15〜）: 管理画面の1つ目のタブは「参加者」。回を選んで誰が来たかを見る（既定は今日の回、無ければ今日までのいちばん新しい回なので、日付をまたいでも前回を見られる）。「開催」タブは既定で「今月から先（全部）」を月ごとに表示。人数は出席タブから数えた今の値で、押すとその回の参加者を開く。中止ボタンは今日から先の回だけ
- **今日の参加（携帯を忘れた人）**（2026-10-10〜）: 管理画面「会員」→ 名前で探す → その人を開く →［今日の参加を記録］。判定は本人が押したときと同じ（券・免除・事務長）。券が無い人は「都度（その場で受け取り）／5回券・入金済み／5回券・未入金で参加」から選ぶ
- **出席の記録・直し**（2026-10-07〜）: 管理画面「会員」→ その人を開く →［出席を記録・直す］で回を選び、初回無料（入会）／券／都度／体験／事務長／取消。押し忘れ・種別の間違いはここで直す（お金の記録は変わらない）
- **全員無料の回**（2026-11-07 第100回記念だけ）: `gas/logic_checkin.js` の `FREE_SESSION` で日付を決めている。その日は会員画面のボタンが［本日参加（100回記念・無料）］になり、種別「100回記念」・0円で記録（券・購入は動かさない。通算には入る。2026-11-17〜 初めて来た人はその日が入会日＝無料の回が初回）。管理画面の［出席を記録・直す］に［100回記念（無料）］が出る。見本は `checkin.html?demo=4`
- **スポーツチャンバラ剣豪**（2026-11-17〜）: 管理画面「参加者」で回を選び、下の［⚔️ スポーツチャンバラ優勝］からその回の出席者を1人選んで［この人を優勝で記録］。選び直すと付け替え、「（優勝なし）」で取消。優勝1回＝剣豪ポイント1。会員画面に本人のポイントと上位5人（同点は同順位・先に届いた人が上）。記録はシートの「剣豪」タブ（初めて使うときに自動で作る）。計算は `gas/logic_kengo.js`
- **ミヤからひとこと**（2026-11-17〜）: 会員画面の［出席する］の下に、参加の様子から自動で選んだ一言（新人・久しぶり・節目まであと少し・参加多数・ゆっくり・いつも・剣豪）。文は `gas/logic_comment.js` の `COMMENT_TEXTS`（耕平さんの見本の口調）で日替わり。部長・免除の人には出ない。外部の AI は呼ばない（費用0円）
- **出席者の札**（2026-11-17〜）: 管理画面「参加者」の名前の下に 通算・出席率・剣豪⚔️（部長・免除は出席率なし）。会員画面「今日の出席」は 通算と剣豪⚔️だけ（出席率はみんなが見るので出さない）
- **券の二重付与を止める**（2026-11-17〜）: 管理画面の［券を付与］で、その人が同じ日にもう券を買っていたら確認が出る（OK なら付与）
- **事務長・副事務長**: 区分は会員カードの［区分を変更］。2人あわせて1回の練習で1人だけ無料（先に出席した人）
- **回数券**: 残り0の会員は自分の画面の［5回券を買う］で購入（購入タブに `未収`、券は即付与）。現金を受け取ったら管理画面「会員」の［入金済みにする］。先に現金を受け取ったときは［券を付与］（入金済み）
- **通算番号**: 過去分 1〜93 を取り込み済み。設定タブ「通算番号の開始」= 1（管理画面で開催を登録すると自動で続き番号）
- **取り込み**（1回きり・実施済み）: 管理画面のトークンで `admin.import {sourceSheetId, initialPin}`。再実行は「すでに取り込み済み」で拒否。行が消えたときは `admin.repairMissing`
- **練習マニュアル**: `v2/manual/`（会員画面の下のボタンから開く）。正本は `kickboxing-club/運営マニュアル/`（このリポジトリの外）。直したら正本側の `tools/アプリ用に書き出す.py` で書き出し、`manual.pdf` を Chrome で印刷し直す。アプリ版は三宅個人の LINE QR を載せない
